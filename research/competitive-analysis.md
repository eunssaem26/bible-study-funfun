# 경쟁/레퍼런스 서비스 분석: 한국 중학생 대상 영어 성경 학습 사이트

**프로젝트 컨텍스트**: 13~15세 한국 중학생을 대상으로, 성경 이야기를 통해 영어를 배우는 무료 웹사이트. 톤은 Duolingo / Cake 수준 (유아 대상도, 무거운 신앙 톤도 아님). 스토리를 한 편씩, 난이도별로 제공.

**조사 방법 주의**: 본 세션에서 WebFetch / WebSearch 권한이 반복적으로 거부되어, 각 서비스의 정확한 최신 가격/UI 세부사항은 사전 지식 기반으로 작성했습니다. 모든 가격 및 구체 수치는 **확인필요** 표시했으며, MVP 기획 전 한 번 더 직접 사이트 방문 검증을 권장합니다.

---

## 1. 스토리텔링형 성경 앱

### 1-1. BibleProject (bibleproject.com)
**무엇을 하는가**: 성경의 책별, 주제별 내용을 5~10분짜리 애니메이션 영상으로 풀어주는 무료 비영리 프로젝트. 화이트보드 스타일 일러스트와 차분한 내레이션이 특징. 영상 외에도 팟캐스트(BibleProject Podcast), 무료 학습 클래스(Classroom), 책별 포스터를 제공.

**따라할 만한 강점**:
- **시각적 메타포 중심 설명**: 텍스트 대신 그림으로 추상 개념을 시각화 — 중학생에게 텍스트 부담을 낮추는 핵심 전략.
- **"한 책 한 영상" 단위로 끊어 보기**: 진입 장벽이 낮은 콘텐츠 청크.
- **무료 + 다국어 자막** (한국어 자막 일부 영상에 존재 — 확인필요): 무료 모델의 좋은 레퍼런스.
- **차분한 톤의 일러스트**: 유아용이 아닌, 디자인-aware한 사용자도 거부감 없는 톤.

**피해야 할 약점**:
- 영상 중심이라 **읽기 학습과는 거리가 멂** — 우리 프로젝트는 텍스트 인터랙션이 필수.
- UI가 영어 위주이며 카탈로그가 방대해 **어디서 시작해야 할지 막막함**.
- 신학 용어가 그대로 등장 — 중학생에겐 진입 장벽.

**스크린샷 가치 있는 한 장면**: 책별 영상 페이지에서 **양피지 두루마리 스타일의 책 구조 다이어그램**이 영상과 함께 펼쳐지는 장면. "이 책의 구조를 한 장에 압축"한 교육적 임팩트가 큼.

### 1-2. YouVersion Bible App for Kids (Bible App for Kids)
**무엇을 하는가**: YouVersion이 만든 어린이용 무료 앱. 성경 이야기를 인터랙티브 애니메이션으로 풀어 탭/스와이프하면 그림 속 요소가 움직이는 형식. 50개 가까운 한국어 포함 다국어 지원(확인필요).

**따라할 만한 강점**:
- **완전 무료 + 광고 없음** 모델 — 비영리 후원 기반. 우리 프로젝트와 정확히 같은 구조.
- **터치 인터랙션이 스토리에 녹아있음** — 단순 영상이 아니라 능동적 참여.
- **챕터 클리어 시 배지/스티커 보상** — Duolingo와 비슷한 게이미피케이션.

**피해야 할 약점**:
- **타깃이 4~8세** — 우리 13~15세에겐 너무 유치함. 캐릭터 디자인, 효과음, 폰트 모두 "키즈".
- 영어 학습 기능 **전무** — 단어 클릭, 사전, 난이도 전환 없음.
- 모바일 앱 only, 웹 미지원.

**스크린샷 가치 있는 한 장면**: 노아의 방주 스토리에서 화면을 탭하면 동물들이 한 마리씩 방주에 들어가고, 비구름을 문지르면 비가 쏟아지는 장면. "탭 = 다음 장면" 전환 패턴이 명확함.

### 1-3. Superbook (CBN, superbook.cbn.com)
**무엇을 하는가**: CBN(미국 기독교 방송)에서 만든 3D 애니메이션 성경 시리즈. 풀 에피소드 무료 스트리밍, 모바일 앱, 어린이 라디오 포함. 시즌제 TV 시리즈 형식.

**따라할 만한 강점**:
- **에피소드별 30분 풀스토리** — "이번 주 한 편" 호흡이 명확.
- **퀴즈 / 게임 모듈 분리**: 영상 시청 후 별도 탭에서 학습.
- 시즌/에피소드 카드 UI가 **넷플릭스와 유사** — 친숙함.

**피해야 할 약점**:
- 디즈니/픽사 흉내를 낸 3D 캐릭터 — 중학생에겐 **B급 키즈 애니메이션**으로 보일 가능성.
- 기독교 색채가 매우 강하고 미국 보수 기독교 감성 — 한국 비신자/탐색 단계 학생에게 거리감.
- 한국어 자막 매우 제한적(확인필요).

**스크린샷 가치 있는 한 장면**: 에피소드 목록 페이지에서 시즌별 가로 스크롤 카드 UI — 각 카드에 에피소드 제목, 썸네일, "Watch / Quiz / Activity" 3-버튼 분기. **콘텐츠 한 개 = 다중 모드 진입점** 패턴이 깔끔함.

## 2. 성경 읽기 / 학습 플랫폼

### 2-1. YouVersion / Bible.com
**무엇을 하는가**: 세계 최대 성경 앱. 5억+ 다운로드(확인필요). 2,000+ 언어, 한국어 번역본 다수(개역개정, 새번역 등) 포함. 핵심 기능: 매일 묵상 플랜, 구절 이미지 카드, 친구와 공유, 오디오 성경, Verse of the Day.

**따라할 만한 강점**:
- **읽기 플랜(Reading Plans)** — 7일/30일 단위로 "오늘 읽을 분량"이 카드 형태로 떨어짐. 우리 MVP의 "오늘의 스토리" 핵심 메타포.
- **Verse Image** — 좋아하는 구절을 인스타그램용 이미지 카드로 변환. 중학생 SNS 공유 동선과 잘 맞음.
- **두 번역본 병렬 보기** — 우리 한↔영 병렬에 그대로 응용 가능.
- **밑줄/하이라이트/북마크** UI 패턴이 표준적.

**피해야 할 약점**:
- **영어 학습 기능 0** — 단어 사전, 발음, 난이도 변환 없음.
- 선택지가 너무 많아 **첫 진입자가 길을 잃음** (어떤 번역? 어떤 플랜?).
- 광고 없는 대신 자체 콘텐츠가 잡다하게 푸시됨.

**스크린샷 가치 있는 한 장면**: 구절 화면에서 한 단어/구절을 길게 누르면 하단에서 **하이라이트·북마크·노트·공유 4-액션 시트**가 올라오는 모먼트. 우리 사이트의 "단어 클릭 → 뜻+발음+예문 팝업"의 직접 모델.

---

### 2-2. Bible Gateway (biblegateway.com)
**무엇을 하는가**: 웹 기반 성경 검색/읽기 플랫폼. 200+ 영어 번역본, 한국어 포함 70+ 언어. 키워드 검색, 병렬 비교, 주석(commentary) 통합, 오디오 성경.

**따라할 만한 강점**:
- **병렬(parallel) 모드**: 최대 5개 번역본을 가로로 나열 — 우리 한국어 + ESV/NIV + Easy English 3단 비교에 응용.
- **검색 기능이 강력**: "love"라고 치면 단어가 나오는 모든 구절. 우리 "이 단어가 등장하는 다른 스토리" 기능에 차용 가능.
- **무료 + 광고 모델이 깔끔** — 인쇄용 페이지, 이메일 구독.

**피해야 할 약점**:
- UI가 **2010년대 초반 디자인** — 텍스트 빽빽함, 정보 밀도 높음. 중학생이 보면 즉시 이탈.
- 모바일 최적화 부족 — 데스크톱 전제.
- 영어 학습 기능 없음.

**스크린샷 가치 있는 한 장면**: 메인 검색창에서 "John 3:16"을 타이핑하면 자동완성으로 책-장-절을 제안하는 입력 UX. **"성경 책 이름을 외우지 못해도 닿을 수 있는"** 검색 패턴.

---

### 2-3. Bible Hub (biblehub.com)
**무엇을 하는가**: 한 구절을 클릭하면 **모든 영어 번역본 + 헬라어/히브리어 원어 + Strong's 사전 + 주석**이 한 화면에 펼쳐지는 학구파 사이트.

**따라할 만한 강점**:
- **한 구절 = 한 페이지에 모든 정보** 구조: 우리도 "한 스토리 = 한 페이지에 모든 학습 자원" 패턴 가능.
- **Interlinear(원문 단어별 분해)**: 영어 단어별 품사·어원 표시 — 중학생용 "단어별 카드" UI로 재해석 가능.

**피해야 할 약점**:
- **목사·신학생 타깃** — 학술적 깊이는 중학생에게 과함.
- UI가 90년대 후반 텍스트 사이트 느낌. 광고 배너 다수.
- 모바일 거의 사용 불가능.

**스크린샷 가치 있는 한 장면**: 한 구절을 클릭하면 그 아래로 **30+ 영어 번역본이 세로로 나열되는** 화면. "같은 의미를 30가지로 다르게 표현했다"가 시각적으로 충격적 — 중학생용으로 3개로 줄여 응용 가능.

## 3. 읽기 기반 언어 학습 앱

### 3-1. Duolingo Stories (Duolingo 내 Stories 섹션)
**무엇을 하는가**: Duolingo 앱 내에서 짧은 대화형 스토리를 읽으며 언어 학습. 문장 한 줄씩 진행하며 듣기, 빈칸 채우기, 단어 매칭, 정렬 문제가 끼어듦. 중간중간 캐릭터 일러스트.

**따라할 만한 강점**:
- **한 화면 = 한 문장** 단위 진행 — 부담 0. 우리 스토리 분할의 정답.
- **문장 클릭 = 듣기 재생** — 따라 읽기 자동.
- **이해도 체크 미니퀴즈가 매 3~5문장마다 끼어듦** — 진도 + 학습이 분리되지 않음.
- 캐릭터(Duo, Lily 등)의 짧은 대사로 **감정·유머** 유지.

**피해야 할 약점**:
- 영어 학습자는 영어로 진입 불가 (영어→스페인어처럼 모국어 기준). **영어를 배우려면 다른 모국어**로 등록해야 함 — 한국 중학생에겐 자연스러움.
- 스토리가 짧고 가벼워서 **깊이 있는 내러티브** 부재.

**스크린샷 가치 있는 한 장면**: 스토리 중 한 문장에 밑줄친 단어를 탭하면 화면 상단에서 **반투명 번역 풍선**이 0.3초 페이드인 — "탭 = 즉시 번역" 인터랙션의 골드 스탠다드.

---

### 3-2. Cake (케이크, mycake.me)
**무엇을 하는가**: 한국 발 영어 학습 앱. **유튜브/드라마 짧은 클립 + 문장별 자막 + 한국어 번역**을 결합. 매일 새 클립이 무료로 제공되고, 클립 안의 한 문장을 눌러 발음 따라하기·녹음·AI 발음 평가.

**따라할 만한 강점**:
- **한국 중고생이 가장 익숙한 영어 학습 UX** — 우리 타깃이 이미 쓰고 있을 확률 매우 높음.
- **문장 단위 카드 + 한국어 자막 토글** — 정답 패턴.
- **"오늘의 표현"** 매일 푸시 — 습관 형성.
- **무료 모델**이지만 광고 + 프리미엄 분리.
- UI 톤이 **밝고 모던, 비종교적, 비유아적** — 우리 톤의 직접 모델.

**피해야 할 약점**:
- 짧은 클립 위주라 **긴 내러티브 학습은 어려움** (성경 스토리는 더 길어야 함).
- 광고가 다소 거슬림.
- 콘텐츠가 K-pop·드라마 중심이라 우리는 다른 콘텐츠 축이 필요.

**스크린샷 가치 있는 한 장면**: 클립 재생 중 한 문장을 탭하면 그 문장만 반복 재생되며 **하단 시트에서 "Listen / Speak / Translate" 3-버튼**이 올라오는 화면. **한 문장 → 다중 학습 모드** 패턴이 우리에게 그대로 이식 가능.

### 3-3. Beelinguapp
**무엇을 하는가**: **병렬 텍스트(parallel text)** 학습 앱. 한 화면 좌우(또는 상하)에 학습 언어와 모국어가 동시 표시. 동화, 뉴스, 과학 텍스트, **성경** 카테고리도 존재(확인필요). 오디오와 함께 읽으면 현재 문장이 하이라이트.

**따라할 만한 강점**:
- **병렬 읽기 + 가라오케 하이라이트**: 듣기와 읽기가 동기화됨. 중학생에게 효과적.
- **카테고리 구조** (동화, 음악, 과학, 종교 등) — 콘텐츠 선택지 명확.
- **무료 콘텐츠 + 프리미엄 잠금** 모델.
- **성경 카테고리가 이미 존재** — 그러나 깊이가 얕음. 우리는 여기를 정조준해 차별화 가능.

**피해야 할 약점**:
- UI가 다소 투박, 광고 적극적.
- 학습 게이미피케이션 약함 — 진도/배지/스트릭 약함.
- 프리미엄 락이 공격적.

**스크린샷 가치 있는 한 장면**: 좌측에 영어, 우측에 한국어가 문단 단위로 나란히 표시되고, 오디오 재생 중인 문장이 **양쪽에서 동시에 노란 하이라이트**되는 화면. 우리 핵심 UI 후보 1순위.

## 4. 한국 기독교 / 영어 성경 자원

### 4-1. 갓피플 (godpeople.com)
**무엇을 하는가**: 한국 최대 기독교 종합 포털. 성경, 묵상(QT), 기독교 도서/음반 쇼핑몰, 커뮤니티, 영어 성경 코너. 갓피플성경 앱 별도 운영.

**따라할 만한 강점**:
- **한국어 + 영어 성경 병렬 읽기** 기능 존재 (NIV 등). 한국 신자 기준의 정답 UX 레퍼런스.
- **QT(Quiet Time) 일일 콘텐츠** — "오늘의 묵상" 카드. 우리 "오늘의 스토리"와 동일 메타포.
- 한국어 UI — 중학생 부모가 안심.

**피해야 할 약점**:
- UI가 **포털 시대 한국 사이트** 그대로 — 정보 과밀, 배너 광고, 90년대 후반 ~ 2000년대 초반 감성. 중학생이 보면 즉시 이탈.
- 쇼핑몰·커뮤니티가 메인이라 학습 동선 약함.
- 영어 학습 기능 없음 (단순 병렬 표시만).

**스크린샷 가치 있는 한 장면**: 성경 페이지에서 한 절을 클릭하면 한국어 / 영어 / 중국어 등 다국어 번역이 위→아래로 쌓이는 모달. **"여러 번역본 = 세로 스택"** 패턴 — 우리는 가로 슬라이드로 변형 가능.

### 4-2. 두란노 (duranno.com) — 생명의 삶, QT 중심
**무엇을 하는가**: 한국 기독교 출판사 두란노가 운영. 대표 콘텐츠는 **생명의 삶**(월간 QT 책자/앱). 매일 한 본문 + 묵상 가이드 + 적용 질문.

**따라할 만한 강점**:
- **하루 한 본문** 호흡 — 매우 한국적이고 검증된 패턴.
- **본문 → 묵상 → 적용** 3단 구조 — 우리 "스토리 → 어휘 → 퀴즈" 3단과 매칭.
- 영어판 QT(Living Life English) 존재(확인필요) — 중급 학습자용 영어 본문 + 한국어 가이드. **우리 프로젝트의 가장 직접적인 한국 경쟁자/레퍼런스**.

**피해야 할 약점**:
- 톤이 **매우 신앙 중심**, 비신자 중학생 진입 어려움.
- 종이 책자 기반의 디지털화라 UI가 정적/세로 스크롤 텍스트 위주.
- 유료 (책자 구독). 무료 학습 앱 시장에 빈자리.

**스크린샷 가치 있는 한 장면**: 생명의 삶 앱에서 **본문 하단의 "오늘의 묵상 질문 3개"**가 카드로 펼쳐지는 화면. 우리 "오늘의 영어 표현 3개 / 퀴즈 3개" 카드 디자인 직접 차용.

### 4-3. GoodTV (goodtv.co.kr) + 한국 유튜브 영어 성경 채널
**무엇을 하는가**: GoodTV는 한국 기독교 방송. 영어 설교/영어 성경 강의 다수. 한편 유튜브에서 **"영어성경 공부"**, **"중학생 영어성경"** 검색 시 다수의 개인 채널이 존재 — 한 절씩 천천히 읽고 단어 풀이를 한국어로 해주는 형식이 다수.

**따라할 만한 강점**:
- 유튜브 영상 형식이 이미 검증됨: **"한 구절 영어 낭독 → 한국어 단어 설명 → 다시 낭독"** 3단 패턴.
- 댓글/공유로 **커뮤니티 형성** 자연스러움 — 우리도 학생 코멘트 시스템 고려.
- 무료.

**피해야 할 약점**:
- **PPT + 교회 어른 보이스 톤** — 중학생 거부감 큼.
- 검색해도 흩어져 있어 **체계적 커리큘럼 부재** (확인필요: 시리즈물은 일부 있음).
- 영상 일방향, 인터랙션 없음.

**스크린샷 가치 있는 한 장면**: 유튜브 영상 화면에 **영어 원문 자막 + 그 아래 한국어 단어 풀이 실시간 추가** 되는 비디오 에디팅 패턴. 우리 인터랙티브 텍스트 버전으로 변환 가치 큼.

## Synthesis (종합)

### MVP 필수 5가지 기능

1. **하루 한 스토리 카드** — Duolingo Stories + 두란노 생명의 삶 + YouVersion Reading Plan의 공통 패턴. 메인 화면 = "오늘의 이야기" 카드 한 장. 진입 부담 0.
2. **3단 난이도 토글 (Easy / Standard / Original)** — 같은 스토리(예: 다윗과 골리앗)를 어휘 수준별로 3버전 제공. 가장 쉬운 버전부터 시작, 자신감 붙으면 다음 단계. Beelinguapp의 병렬 + 자체 단계 시스템.
3. **단어 탭 = 즉시 번역 + 발음 + 예문 팝업** — Cake / Duolingo Stories / LingQ의 골드 스탠다드. 사전 검색으로 이탈하지 않게.
4. **문장별 오디오 + 가라오케 하이라이트** — Beelinguapp 패턴. 듣기-읽기 동기화. TTS로 저비용 구현 가능.
5. **스토리 끝 = 3문제 미니 퀴즈 + 진도 배지** — Duolingo의 게이미피케이션. 단, 배지 디자인은 **유아 톤 금지** (Cake 톤 참고).

### 명시적으로 하지 말아야 할 것 3가지

1. **유아용 캐릭터/효과음/풍선체 폰트 금지** — Bible App for Kids, Superbook 함정. 13~15세는 "어른 같은 디자인" 선호. Cake와 Duolingo의 미니멀-모던 톤 유지.
2. **신학 용어 직진 금지** — "구속(救贖)", "이신칭의" 같은 용어 일절 금지. 스토리 전달이 1순위, 신학은 0. BibleProject도 이 함정에 부분적으로 빠져 있음.
3. **포털형 정보 과밀 UI 금지** — 갓피플, Bible Hub, Bible Gateway가 빠진 함정. 한 화면 = 한 가지 액션. 사이드바·배너·추천 모듈 최소화.

### 가장 가까운 분석 대상 2곳

- **Cake (케이크)**: 톤·UX·타깃 한국 중고생이라는 점에서 가장 직접적인 모델. 우리는 "Cake의 콘텐츠 축을 짧은 클립 → 성경 스토리로 교체"한 형태가 합리적 출발점.
- **Duolingo Stories**: 스토리 진행 + 인터랙션 + 게이미피케이션 + 게스트 학습 흐름의 정답. 우리는 여기에 "성경 스토리 + 한국어 모국어 + 무료" 조합을 더한 변종이 됨.

위 두 서비스의 인터랙션 패턴(문장 단위 진행, 단어 탭 번역, 문장 끝 미니퀴즈, 진도 스트릭)을 그대로 이식하고, 콘텐츠 큐레이션은 두란노 생명의 삶의 "하루 한 본문 → 묵상 → 적용" 한국식 호흡으로 채우면 MVP 청사진이 완성됩니다.
